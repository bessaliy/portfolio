About the project

Sedona was my first frontend project built from a provided Figma design.

The goal was to learn the fundamentals of HTML and CSS and understand how a website is structured from the ground up.

The project includes several pages, basic interactions, and a modal window.

The challenge

As my first frontend project, the biggest challenge was understanding how layouts are built and how different HTML and CSS concepts work together.

I had to learn semantic markup, positioning, spacing, and how to turn a static design into a functional website.

Screenshots

Lessons learned

This project showed me that frontend development is much more than writing HTML tags.

It was the first time I transformed a design into a real website and learned how structure, layout, and visual details come together in the browser.
